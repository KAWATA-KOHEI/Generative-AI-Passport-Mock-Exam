# 生成AIパスポート 問題集

全60問。スマートフォン・PCに対応した学習用問題集です。

- 自動採点、選択肢ごとの解説
- 分野別・未回答・苦手問題の復習、検索、ランダム10問
- Googleログインによる回答履歴・見直し・復習リストの同期
- 「解説を確認した」「まだ不安」「理解できた」の記録
- ログインせず、このブラウザだけに記録して学習することも可能

公開URL: https://kawata-kohei.github.io/Generative-AI-Passport-Mock-Exam/
